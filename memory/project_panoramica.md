Repository creato il 2026-08-05 come cartella di lavoro Blender per il progetto "PaperDiceTower". Inizializzato come repository git locale nuovo in E:\repos\PaperDiceTower.

**Perché:** l'utente vuole usare il connettore Blender per creare un file .blend che riceverà un prompt di modellazione in un secondo momento (non ancora fornito al 2026-08-05).

**Come applicarla:** lo scopo esatto del modello (es. dimensioni, meccanica di caduta dei dadi, se pensato per stampa 3D o taglio/piegatura carta) va confermato dal prompt che l'utente fornirà; aggiornare questa memoria non appena arriva.

Vedi [[reference-memoria-su-disco]] per la policy di memoria di questo progetto.
